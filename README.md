# Python-DA-Assignment 

 Python DA Assignment 1 – Data Analysis using NumPy and Pandas

Assignment Overview

This assignment focuses on learning and implementing fundamental data analysis operations using Python libraries such as NumPy and Pandas.

The assignment covers creating arrays, performing numerical computations, working with Pandas Series, and exploring and manipulating DataFrames.

Tools Used

Python 
Jupyter Notebook
NumPy
Pandas

Tasks Completed

NumPy Array Operations

- Created 1D and 2D NumPy arrays using temperature data for two weeks.
- Inspected array shape, data type, and number of elements.
- Converted Celsius temperatures into Fahrenheit.
- Calculated maximum, minimum, and mean temperatures.
- Performed array slicing and indexing.
- Extracted weekday and weekend temperature data.

Pandas Series

- Created a Pandas Series with student marks and custom index labels.
- Performed indexing using integer positions.
- Retrieved values using `loc` and `iloc`.
- Applied Boolean masking to filter marks greater than 90.
- Modified student marks.
- Removed an entry from the Series.
- Calculated CGPA by dividing marks by 10.

Pandas DataFrame

- Created a DataFrame named `transactions` containing transaction details.
- Explored data using `head()`, `tail()`, `shape`, `columns`, `dtypes`, and `info()`.
- Selected specific columns.
- Retrieved columns using `iloc`.
- Filtered transactions based on multiple conditions.
- Calculated value counts for product categories.
- Identified unique regions.
- Grouped transactions by region and calculated the mean amount.
- Modified transaction amounts.
- Added a Discount column representing 10% of the transaction amount.
- Removed a transaction using its TransactionID.
- Deleted the Discount column.

 Key Concepts Practised

- Array creation and manipulation
- Array indexing and slicing
- Numerical computations
- Series creation and manipulation
- DataFrame creation and exploration
- Data filtering and selection
- GroupBy operations and aggregation
- Data modification and deletion

Learning Outcome

Through this assignment, I gained practical experience in using NumPy and Pandas for numerical computations, data exploration, filtering, and manipulation.
